# Matheus Wachtler's Online Resume

This is the repository for Matheus Wachtler's online resume, developed in HTML and CSS. The site provides detailed information about Matheus Wachtler's professional experience, education, certifications, courses, and projects.

## Project Structure

The project consists of the following main files:

- `index.html`: Home page of the site.
- `cv.html`: Resume page.
- `style.css`: CSS stylesheet.
- `README.md`: This documentation file.

## Features

- **Navigation**: Buttons to navigate between the home page and the resume page.
- **Download PDF**: Button to generate and download the resume in PDF format.
- **Sections**: Contact information, general information, education, certifications, courses/trainings, projects, and professional experience.
- **Styling**: Custom styles to highlight important information.

## Technologies Used

- HTML5
- CSS3
- Font Awesome (for social icons)

## How to View the Project

1. Clone this repository to your computer:
    ```bash
    git clone <REPOSITORY_URL>
    ```

2. Navigate to the project directory:
    ```bash
    cd Resume
    ```

3. Open the `index.html` or `cv.html` file in your preferred browser.

## HTML Structure

- **Header**: Contains navigation buttons and contact information.
- **Main Content**: Includes detailed sections about professional experience, education, certifications, courses, and projects.

## CSS Styles

- The `style.css` file contains all the style rules applied to the site.
- The `.highlight` class is used to emphasize important text, making it bold, larger, and uppercase.
